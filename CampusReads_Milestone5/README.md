# CampusReads — Milestone 5 practice prototype

This is a clickable local demo based on the TASK-UIUX-04 starter brief.

## Run it
Open `index.html` in a web browser. Click **View Details**, then **Back to Browse** to test the required forward-and-back flow.

## Test notes
- Ordinary case: Browse → Book Details → Browse.
- Boundary case: Open the Book Details screen in the demo, use Back, and confirm Browse returns with the sample listing intact.
- Learning: Explicit navigation labels and a clear start screen make a short prototype easier to test.

All book and student details are fictional. The Request Book control only shows a demo confirmation; it does not send a request.
